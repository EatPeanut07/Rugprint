# Fair Launch Firewall

V5 stores behavioural evidence, review signals, a denylist database, and an appeal path.

Automated participation data alone cannot trigger a restriction. A block evaluation requires documented corroborating evidence plus the configured confidence and false-positive thresholds.

There is no real on-chain wallet blocking in V5. Any future enforcement should use a separate audited Solana program with deterministic rules, transparent policy, emergency shutdown, and an appeal/removal process.
