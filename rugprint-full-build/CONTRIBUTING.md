# Contributing

RugPrint values reproducible evidence over confident-sounding labels.

For new detection rules, include:
1. what observable fact the rule reads
2. why it is relevant
3. plausible innocent explanations
4. a confidence category
5. a transaction/address source where possible
6. tests or sample transactions when available

Do not submit rules that attempt to infer protected traits, private identity, home address or other doxxing information.
